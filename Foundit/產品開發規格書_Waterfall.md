## 一、專案概述

### 1.1 產品定位

「找得到」為台灣版失物共享平台 APP，參考韓國 FindingAll 模式，整合遺失物登記、撿到物登記、AI 配對、地圖搜尋、聊天聯絡、賞金系統、QR 防丟貼紙等功能。

### 1.2 目標用戶

| 用戶類型 | 使用情境 |
|---------|----------|
| 遺失者 | 遺失物品後登記、搜尋、懸賞、接收配對通知 |
| 撿到者 | 撿到物品後登記、配對、聯絡失主 |
| 一般民眾 | 瀏覽附近遺失物、協助分享傳播 |
| 政府單位 | 整合警察局、捷運等官方失物招領資料 |

### 1.3 開發模式：Waterfall 瀑布式

```
需求分析 → 系統設計 → 實作開發 → 測試驗收 → 部署上線 → 維護營運
   ↓          ↓          ↓          ↓          ↓          ↓
  SRS       SDD        Code       Test       Deploy     Ops
```

## 十、風險與假設

| 風險 | 影響 | 緩解措施 |
